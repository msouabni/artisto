# Spec MEP v0 — Modèle de données + flow pipeline

Date : 2026-05-10
Source : vision utilisateur 2026-05-10 (post-clôture séquence P3 transferts + Vague A).

## Posture

MEP v0 = première publication plateforme avant stabilisation complète. Pipeline simple, droit au but. ERNIE uniquement (pas de support multi-modèle image v0). Données de référence initiales = skill `prompt-taxonomy-ecosystem`.

## Modèle de données cible

```
taxonomy (existant)
└── term (existant, feuille taxonomie)
    └── subject (NOUVEAU — anciennement appelé "concept" dans la discussion)
        ├── id, term_id, name, source ('skill_v0' / 'manual' / etc.)
        ├── tags: list[str]    # {ambigu, simpliste, incomprehensible, creatif, parfait, complique, bug, blacklist}
        ├── note: int 0-6      # informatif, non bloquant
        ├── status: enum       # draft | annotated | validated | enriched | prompted | generated | qc_done | published | rejected
        ├── enrichment (i18n)  # title, description, meta SEO EN/FR/AR
        ├── prompt             # positive (negative figé côté workflow)
        └── image_output (existant)
            ├── qc_tags        # auto-générés (cf. QC simple ci-dessous)
            └── validation_status  # via annotation polymorphe target_type='image_output'
```

Règles de filtrage par tag (configurables par term) :
- `blacklist` → bloque définitivement (jamais générer).
- `bug` / `incomprehensible` / `simpliste` / `ambigu` → bloque par défaut, réactivable manuellement.
- `complique` → passe avec drapeau de vigilance.
- `creatif` / `parfait` → passe sans restriction.
- Note 0-6 : informatif, peut servir de tri secondaire.

## Flow pipeline MEP v0

```
[1] Import skill v0 (one-shot)
    └─ Charge subjects depuis skill `prompt-taxonomy-ecosystem` → table subject
       Source : ref skill, status='draft'
       ↓
[2] Annotation de masse (humain + annotateur v2)
    └─ Tags + note via annotateur HTML (target_type='subject' polymorphe existant)
       ↓
[3] Filtrage par tags + règles par term
    └─ subject.status='validated' si pass filtre
       ↓
[4] Enrichissement i18n (job)
    └─ ai_pipeline_worker (qwen3.5:4b) génère title/desc/meta EN/FR/AR
       subject.status='enriched'
       ↓
[5] Préparation prompt (job)
    └─ PromptGenerator.build_prompt(term_id) → positive
       subject.status='prompted'
       ↓
[6] Génération image (job)
    └─ image_worker (ERNIE-only direct ComfyClient) → image_output
       subject.status='generated'
       ↓
[7] QC automatique (job)
    └─ Tags simples sur image_output (cf. QC simple ci-dessous)
       subject.status='qc_done'
       ↓
[8] Queue validation utilisateur
    └─ Annotateur HTML mode 'image_output' (déjà en place via greffon prod)
       Validation par échantillon / filtre / au cas par cas
       subject.status='published' ou 'rejected'
       ↓
[9] Publication plateforme (job)
    └─ Export Alwan Books selon contrat
       Sujet sorti vers plateforme
```

## QC automatique — design simple, droit au but

Concept : QC = job qui pose des tags sur `image_output` selon des règles déterministes, **sans LLM**. Le QC ne tranche pas — il informe l'utilisateur en validation.

Tags QC proposés (minimal, extensible) :

| Tag | Règle de détection | Coût |
|---|---|---|
| `qc_color_residual` | `color_ratio > 0.001` (Pillow histogram, existe déjà) | <0.5s |
| `qc_color_intrinsic` | leaf_id ∈ {`rainbow_*`, `crystal_*`, `prism_*`} (whitelist) | instantané |
| `qc_low_contrast` | std intensité < seuil | <0.5s |
| `qc_low_complexity` | nombre d'edges (Canny) < seuil → image probablement vide | <1s |
| `qc_oversaturated` | percent pixels noirs > 50% → trop d'encre | <0.5s |
| `qc_ok` | aucun des tags ci-dessus | instantané |

Pas de QC vision LLM (déjà invalidé empiriquement). Pas d'auto-décision : l'utilisateur tranche en queue de validation avec les tags QC comme guide.

## Tout passe par jobs (queue + scheduling)

Job types nouveaux ou à confirmer :

| Job type | Worker | Cible | Priorité par défaut |
|---|---|---|---|
| `subject_import` | one-shot script | Initial subjects from skill | manual / one-shot |
| `subject_enrichment_i18n` | text_worker | Génère i18n meta | normale |
| `subject_prompt_generation` | text_worker (sync, no LLM) | Calcule positive via PromptGenerator | normale |
| `image_generation` | image_worker (simplifié) | ERNIE direct ComfyClient | normale |
| `image_qc_auto` | new qc_worker (sync, no LLM) | Tags QC déterministes | haute |
| `subject_publication` | new publish_worker | Export plateforme Alwan Books | basse (batch) |

Les jobs respectent la mécanique `BaseWorker` (heartbeat, retry, auto-disable).
